{{< project name="boxer" url="https://github.com/fenwickyduck/boxer" meta="Python · FastAPI · SQLite · Claude Code CLI" >}}
A comprehension engine for dense academic texts. Drag a box around the passage that stopped you and it becomes cards; a card you don't follow pushes a new frame onto the stack, and comes back once the subtree under it is exhausted.
{{< /project >}}

{{< project name="advisor" url="https://github.com/fenwickyduck/advisor" meta="Python · FastAPI · SPECTER · MCP" >}}
A local advisor for research papers. It ranks 76,000 arXiv `cs.CR` and Cryptology ePrint abstracts against what you've read, and over MCP you can talk that reading over with an AI assistant and tell it where to go next, which it writes into the profile the ranking uses.
{{< /project >}}

{{< project name="pdf2csv" url="https://github.com/fenwickyduck/pdf2csv" meta="Python · CLI · TOML" >}}
A self-verifying command-line tool that converts bank statement PDFs to CSV. It rebuilds tables from raw word coordinates and keeps each bank's layout in a TOML config, so a new bank needs no code.
{{< /project >}}
