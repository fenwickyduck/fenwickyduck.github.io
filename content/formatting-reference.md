## Headings and body text

Body copy is IBM Plex Sans at a measure of about 68 characters. Headings are
Bodoni Moda, which is why they're only used large — a didone falls apart at
small sizes. Paragraphs carry **bold**, *italic*, `inline code`, and
[links](https://gohugo.io), underlined thinly with a generous offset.

### A third-level heading

Hover a heading to reveal its anchor. The anchor is keyboard-focusable, so it
isn't hover-only.

#### A fourth-level heading is a mono label

Because at that depth it's doing the job of a label, not a title.

## Code

Fenced blocks get syntax highlighting that follows the theme:

```cpp
// Gaussian lattice reduction in two dimensions.
pair<Vec, Vec> reduce(Vec a, Vec b) {
  if (norm(a) < norm(b)) swap(a, b);
  while (norm(b) < norm(a)) {
    long long m = llround(dot(a, b) / (double)norm(b));
    a = a - m * b;
    swap(a, b);
  }
  return {b, a};
}
```

```haskell
primes :: [Int]
primes = sieve [2..]
  where sieve (p:xs) = p : sieve [x | x <- xs, x `mod` p /= 0]
```

Long lines scroll inside the block rather than pushing the page sideways:

```
$ hugo --gc --minify && du -sh public   # a very long command line that will certainly overflow the measure on a narrow screen
```

## Maths

Inline maths goes in single dollars: a lattice $L = \{ \sum_i a_i b_i : a_i \in
\mathbb{Z} \}$ generated by a basis $B = (b_1, \dots, b_n)$. Display maths goes
in double dollars:

$$\lambda_1(L) \;\le\; \sqrt{n} \cdot \det(L)^{1/n}$$

Both are rendered to MathML when the site builds, so no maths library or font
reaches the reader. Long expressions scroll inside their own box.
